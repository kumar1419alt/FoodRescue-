# FoodRescue Project Specification

## Purpose

FoodRescue will help organizations redirect safe, quality surplus food to community partners that can distribute it.

## Initial scope

- A public-facing web experience.
- Future workflows for food donors and nonprofit organizations.
- Secure authentication and a managed donation lifecycle in later phases.

## Technical baseline

- Next.js with the App Router and TypeScript.
- Tailwind CSS for styling.
- ESLint and TypeScript strict mode for code quality.

Advanced product and database functionality is intentionally deferred until its respective phase.
